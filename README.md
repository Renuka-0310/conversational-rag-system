# Conversational RAG System (Master’s Thesis)

This project implements a conversational Retrieval-Augmented Generation (RAG) system.

## Key Features
- Hybrid retrieval (BM25 + semantic embeddings)
- LLM-based query rewriting
- Memory compression using summarization
- Multi-turn conversational question answering

## Tech Stack
- Python
- LLM APIs
- Vector embeddings

## Experiments
- Baseline (BM25 + full history)
- Retrieval + generation
- Retrieval-only
- Full pipeline (hybrid + rewriting + memory)
